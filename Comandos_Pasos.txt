5. HACER QUE FUNCIONE CON POSTGRESQL EN UNA NUBE RENDER. DOCUMENTAR EL PROCESO DE DESPLIEGUE EN UN FICHERO MARKDOWN.

Crear .gitignore
.venv/
__pycache__/
*.pyc
.env


cd RUTA/DE/TU/PROYECTO
git init
git add .
git commit -m "Proyecto FastAPI_PostgreSQL"


Crear repositorio en GitHub
New repository.
Nombre: fastapi-coches.
Lo creamos vacío (sin README, sin .gitignore, sin licencia).


git remote add origin https://github.com/TU_USUARIO/fastapi-coches.git
git branch -M main
git push -u origin main


Crear la base de datos PostgreSQL en Render:
servicio de base de datos PostgreSQL
En el panel de Render, pulsamos New → PostgreSQL (o similar).
Nombre: cochesdb (o similar).
Región: la que queramos (mejor cercana).
Plan: el gratuito si está disponible.
Creamos la base de datos.
Obtener la URL de conexión

Entramos en el servicio PostgreSQL en Render.
Buscamos la sección Connection o Internal Database URL / External Database URL.
Copiamos la URL de conexión, que tendrá una pinta similar a:
postgresql://usuario:password@host:puerto/nombrebd


Crear el servicio web de FastAPI en Render:
En Render, pulsamos New → Web Service.
Elegimos Build from a Git repository.
Conectamos nuestra cuenta de GitHub (si no lo hemos hecho antes).
Seleccionamos el repositorio fastapi-coches.
configuración inicial
Name: fastapi-coches (o similar).
Region: la misma que la base de datos, si es posible.
Branch: main.
Runtime: Python.

Configurar la variable de entorno DB_URL
En la sección de Environment / Environment Variables del servicio web:
Name: DB_URL
Value: la URL de conexión de PostgreSQL que copiamos antes de Render.

Guarda los cambios.
Vuelve al panel principal del servicio web y pulsa Manual Deploy → Clear build cache & deploy.

https://TU_SERVICIO.onrender.com/
https://TU_SERVICIO.onrender.com/coches


Realizar pruebas:
Modificar algo en el proyecto
